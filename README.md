# Team 7 Personal Finance Agent

A personal finance app to track income,
expenses, and monthly budgets.

## Features
- Income and expense tracking
- Monthly budget dashboard
- AI-powered financial insights
- AI chat assistant

## Technology
- Python
- Streamlit
- Pandas
- Plotly
- Google Gemini API

## Run locally
1. Install Python.
2. Install dependencies:
   pip install -r requirements.txt
3. Configure GEMINI_API_KEY securely.
4. Run: streamlit run app.py
