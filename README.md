# Team 7 Personal Finance Agent

A personal finance app to track income,
expenses, and monthly budgets.

## Features
- Income and expense tracking
- Monthly budget dashboard
- AI-powered financial insights
- AI chat assistant

## Technology
- Python
- Streamlit
- Pandas
- Plotly
- Google Gemini API

## Run locally
1. Install Python.
2. Install dependencies:
   pip install -r requirements.txt
3. Configure GEMINI_API_KEY securely.
4. Run: streamlit run app.py
Deployment Instructions

The Team 7 Personal Finance Agent is deployed using Streamlit Community Cloud.

Deployment Steps

1. Push the project files to a GitHub repository.
2. Ensure that "app.py" and "requirements.txt" are available in the repository.
3. Visit https://share.streamlit.io/ and sign in with GitHub.
4. Click Create app.
5. Select the repository, the "main" branch, and "app.py" as the main file.
6. Add the required API keys and authentication credentials in the Streamlit secrets settings.
7. Click Deploy and wait for the application to start.
8. Open the generated URL and test the application.

Security Notes

- Do not commit API keys, OAuth client secrets, or other credentials to GitHub.
- Configure authentication credentials and redirect URLs correctly.
- Test the deployed application before sharing its URL.
